# 薄肌战神教练 · Lean Muscle Coach

围绕薄肌、减脂增肌与长期健康习惯的中文 AI 健身教练 Skill。建立你的 `muscle.md` 档案，把训练、饮食、睡眠和恢复连起来，在每次对话中给出适合当下的行动。

![薄肌外形示意：适量肌肉、清晰线条与协调比例](assets/lean-muscle.png)

*图源来自薄肌教父，用于展示目标方向；个人体型、起点和进度各不相同，不代表训练效果承诺。*

## 我们追求什么

“薄肌”在这里指适量肌肉、较清晰的身体线条和协调比例。关注肩、上胸、背部与腰腹，也保留腿部训练；同时看力量、围度、恢复和执行情况。

训练进步、蛋白质摄入、与目标匹配的能量摄入，以及能长期坚持的生活安排，是计划的四个支点。计划会随实际反馈调整。

## 你可以用它做什么

| 场景 | 教练会如何帮助你 |
| --- | --- |
| 第一次使用 | 分步了解基础数据、健康限制、训练经验、器材、时间和饮食作息，建立档案；不知道腰围也能开始 |
| 制定计划 | 根据起点安排力量训练、有氧、休息、饮食、动作替代和进阶规则 |
| 器械不会用 | 根据名称、描述或可选照片帮助识别，说明调节、起始姿势和动作步骤，必要时提供替代 |
| 准备去练 | 结合当天状态、上一餐、可用时间与器材，适配当次训练 |
| 刚练完 | 主动考虑进食、补水与恢复，结合上一餐、下次训练和作息给出即时建议 |
| 外卖、家常饭、聚餐 | 给出可执行的搭配和份量选择，兼顾总摄入、营养与个人偏好 |
| 睡不好、疲劳或表现下降 | 关联训练时段、负荷、咖啡因、进食和压力，提出可回退的小调整并观察反馈 |
| 加班、出差、漏练 | 缩短训练、替换动作或安排重启，降低持续执行的负担 |
| 周复盘、体重平台 | 结合有日期的体重、围度、训练与恢复记录，判断继续还是调整 |

## 开始使用

在支持自定义 Skill 的工具中，按该工具的方式加载完整技能目录，选择或调用 `lean-muscle-coach`。AI 的执行入口是 [SKILL.md](SKILL.md)，本 README 供使用者了解功能。

首次使用可以直接发送：

> 开始带我练薄肌，先建立我的 muscle.md 档案。

教练会复用你已经提供的信息，分步补充必要内容。围度、照片、精确体脂和完整饮食日志都不是开始的前提；不想提供的资料可以明确跳过。

已有档案时，可以发送：

> 请读取我的 muscle.md，结合最近的训练和恢复情况，安排接下来一周。

如果工具尚未加载这个 Skill，需要先完成加载；发送技能名称本身不会安装技能。

## 日常就像和教练聊天

不需要每次填一张完整表格。告诉教练你此刻遇到的事即可，需要时再补充一两个会影响决策的信息。

| 可以这样说 | 这轮对话的重点 |
| --- | --- |
| “我刚练完，已经离开健身房了。” | 当下饮食、补水和恢复需求，再补必要记录 |
| “这台坐姿划船怎么调？我不会。” | 先学会操作、选重和动作控制 |
| “最近晚练后不好入睡，明天还练吗？” | 结合训练与生活因素判断当次适配，约定观察指标 |
| “今天只能练半小时。” | 按优先级压缩当天训练 |
| “今晚吃外卖，帮我搭一顿。” | 给出能下单或照做的选择 |
| “这是最近两周的体重和训练记录，帮我复盘。” | 核对数据和执行，判断是否需要调整 |
| “今天只记录，不需要建议。” | 按你的范围保存真实记录 |

教练会考虑快碳、蛋白质、电解质等是否适用，再给建议；遇到失眠，也会核对相关因素，避免把症状直接归因于皮质醇。调整会说明观察什么、何时复查，以及何时停止或回退。

## muscle.md 记录什么

`muscle.md` 是持续更新的个人档案，包含基础信息、目标、当前计划、实际训练、身体与饮食记录、恢复状态、复盘和调整历史。

- **事实有来源**：区分用户报告、测量、估算和待验证解释；未测的数据保留为未知。
- **计划与完成分开**：计划练三组，不会自动记为实际完成三组。
- **保留历史**：修改计划和纠正数据时留下必要记录，方便判断进展。
- **按意愿保存**：可以只聊天、不保存，或要求导出、纠正、停止记录和删除可管理的数据。

真实个人档案与技能源码分开保存，分享技能包时只包含空白模板。跨会话保存取决于运行环境是否提供持久文件能力；无法保存时，教练会说明并提供可带走的档案文本。

## 使用范围

提供一般健身和健康饮食辅导；涉及持续症状、疾病或用药时，结合专业评估安排适合的训练支持。训练效果因起点、身体情况和执行而异。
