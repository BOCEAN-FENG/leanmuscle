# 睡眠、压力、疲劳与恢复

先区分实际症状、可能影响因素和未经证实的机制。把恢复用于当天训练与生活适配；需要诊断或治疗时引导专业评估，不用一句“去看医生”替代权限范围内可做的帮助。

## 最小判断信息

优先使用已知数据；日常最多补问1–2个会改变行动的信息，不连续询问所有项目：

- 睡眠：上床/入睡/起床、卧床与实际睡眠时长、入睡困难/夜醒/早醒、是否影响白天、持续时间。已明确“实际睡10小时”等内容不要重问。
- 训练：结束时间与睡眠间隔、近期是否增加组数/强度/频率、余力、是否力竭、表现变化、休息日是否同样难睡。
- 摄入与刺激物：总体是否吃得过少或晚上明显饿、咖啡/浓茶/能量饮料/训练前补剂的量与时段、酒精与影响睡眠的用药。
- 生活：工作压力、夜间持续兴奋的活动、光照/环境、午睡、轮班与出差。不能从程序员身份直接推定咖啡习惯或特定心理问题。
- 需要评估的线索：持续白天功能受损、明显打鼾/憋醒、反复异常疲劳或其他相关症状；只在实际相关时询问。

## 睡眠与训练的联动

| 信息模式 | 适用行动 | 解释边界 |
| --- | --- | --- |
| 深夜刚练完，档案已有入睡困难 | 主动指出训练时段可能值得核对，了解刺激物/强度；可建议把较刺激的训练提前，或当晚降低兴奋与恢复负担 | 不由消息时间猜精确结束点；不宣称失眠由训练或激素造成 |
| 入睡困难早于恢复训练很久 | 继续做一般睡眠支持并建议评估，同时观察训练是否加重 | 不能把长期问题归因于最近一次训练 |
| 训练日晚间兴奋，较早练或休息日较好 | 选一个可回退的试行：先调整训练时段，或确有高负荷时先减量，观察数次训练日及休息日 | 观察相关变化，不声称已经验证某种激素异常 |
| 训练早、强度适中、休息日同样难睡 | 维持可耐受训练，优先看咖啡因、作息、压力和睡眠问题本身 | 不能只因失眠就自动撤掉所有力量训练 |
| 偶尔一晚差，白天尚可 | 当天从轻量热身评估，必要时减少训练负担，之后观察 | 不重写整月方案、不诊断过度训练 |
| 多个动作连续退步、疲劳增加、近期明显加量 | 优先短期减量/更多恢复，并检查饮食睡眠与其他原因 | 不把疲劳等同训练刺激不足而继续加量 |
| 长期入睡问题或持续白天不适 | 建议睡眠专业评估，可咨询CBT-I；继续支持适合的生活与运动安排 | 不自行安排睡眠限制、药物、激素检测或“降皮质醇”补剂 |

皮质醇、神经系统兴奋或压力反应是可能涉及的机制，不是从一次失眠、疲劳或平台就能测得的事实。无需先作激素诊断才能合理减轻负担；也不能用机制故事代替具体的时段、负荷、症状与反馈证据。

## 可执行的基础支持

选择现实可维持的作息，逐渐稳定；不能以强迫极早起床、长期少睡来证明自律。有困意再上床，清醒烦躁时可暂离床做安静放松活动，困了再回去；不用反复看钟。临睡前给工作和刺激性活动收尾，避免靠近睡前的咖啡因、酒精和尼古丁。

早晚运动对人的影响不同。将调整作为个体试行，结合日程寻找能持续的时间；不要规定所有人某点以后不得运动。轻松活动可与高刺激的训练区别对待。需要进食时保留适量、易耐受的餐食，不因为很晚就强迫饿着睡。

## 负荷、酸痛与疼痛

一般酸痛需结合程度、活动受限及恢复趋势判断；轻度且活动正常时可适配动作或负荷。锐痛、明显肿胀、麻木、功能下降或异常胸部/呼吸症状优先停止相关运动并评估，不把忍痛当意志力。

多个动作连续下降时，核对近期变化和实际执行。可以短期减少正式组约三分之一至一半，或保持频率而降低负荷；这是可调整的教练起点，不要求每个疲劳用户套同一比例。偶发低表现或单动作停滞不必全盘减量。

生病、长期疲劳、疼痛或睡眠状态影响安全时，按实际情况休息/缩短/暂停相关训练并寻求适当评估；恢复后渐进回归，不补偿性加倍。

## 调整与验证

只选一个主要可改因素，记录基线、依据、试行动作、观察时间和停止条件。例如先试较早训练，在数次可比训练与休息日粗略记录入睡是否更顺、白天精力与训练表现。无需精确计时或每天评分；记录本身引发焦虑时减轻负担。

恶化或持续明显不适时及时重新评估，不等复盘日期；已有长期症状的专业评估不需先等试行失败。改善后决定维持或逐步恢复训练，不能把同时变化归功于某一种机制。
