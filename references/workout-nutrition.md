# 训练前、中、后的营养与补水

用于一般健康成人。先遵守疾病、用药、过敏、孕期/未成年人及进食障碍等适用边界。结合全天能量与营养、进食耐受和目标，不把任何时机规则当作必须精确完成的任务。

## 训练前

关注上一餐的大致时间和组成、是否明显饥饿/乏力、训练时长强度，以及是否接近睡眠。此前已吃合适餐食、状态好时正常开始，不为执行技能要求额外加餐。

若很久没吃且即将训练，可以先选一份平时耐受、易消化的含碳水食物，按需要配少量蛋白；有时间则正常吃饭并留消化时间。靠近开练时避免突然大份油腻、高纤维或陌生食物。空腹是否合适取决于状态、目标与限制，不能宣称空腹必然更减脂或一律禁止。

有睡眠问题或晚间训练时主动检查咖啡、浓茶、能量饮料和训练前补剂，不能默认建议刺激物。对不适或长期限制优先适配，不要求硬顶训练。

## 训练中

一般短时力量训练可按口渴与实际出汗喝水，不要求每次运动喝糖水或电解质。时长明显延长、持续高强度、炎热环境或大量出汗时，碳水、液体与电解质需求可能不同，先了解情况再给更具体安排。

不适时先停止相关活动、转到安全处，了解实际症状；不能仅凭出汗、饥饿或头晕就诊断低血糖，也不能把饮料当作继续训练的充分条件。持续或明显异常按安全资料处理。

## 训练后：收到“练完了”就进行本段判断

先利用已有信息，内部关注：之前吃得如何、下一餐多久、这次大致消耗、何时再练、今天剩余营养，以及时间与睡眠。通常只问其中最关键的1–2项；不知道每组重量不阻止给恢复建议。

| 已知条件 | 建议方向 |
| --- | --- |
| 随后能正常吃饭，训练前也吃过，状态正常 | 正餐安排蛋白质、主食和蔬菜，补适量水；不额外强推快碳或蛋白粉 |
| 距离上餐久、明显饿，正餐还要等 | 可选小份易执行的含蛋白与碳水食物作过渡，随后正常进餐；只补有需要的部分 |
| 已经吃过合适训练后餐 | 不重复加餐；结合全天目标和恢复即可，不制造错过窗口的焦虑 |
| 消耗较大且数小时内还要进行高消耗训练 | 提高及时补碳水与液体的优先级，可选择易消化/较快供能来源；按运动量、恢复间隔和耐受具体安排 |
| 接近睡眠且已有入睡困难 | 同时处理吃饭和睡眠：需要时吃适量易消化餐食，避免很大份油腻餐和刺激物；不强迫空腹入睡，也不因“窗口”硬塞大量食物 |
| 大量出汗/炎热或长时间活动 | 关注液体与盐分恢复，可通过合适饮食/饮料完成；不强行灌水 |

把“快碳”作为有条件的选择。快速糖原恢复在恢复窗口很短时更受重视；普通隔日训练的重点仍是全天足够营养和可持续进餐。不要固定“所有人练后30分钟必须吃糖”，也不能一律认为碳水时机没有价值。

蛋白质时机要结合训练前进食与全天摄入。如果需要过渡加餐，可把常见约20–40g蛋白的食物份量作为参考，再考虑体型和总目标；没有缺口就不额外补。食物总重量不等于蛋白重量，按标签与实际份量估算，奶、蛋、豆、肉等依据耐受选择。

举食物例子时用普通正餐、面包/饭等主食配蛋奶豆肉等熟悉来源，不将某一种水果的GI、某一种补剂或某个精确分钟包装为普遍标准。推荐食品前尊重已知过敏/忌口。

## 补水

普通情境按口渴、环境与出汗逐步补水，并正常吃饭；长时间大量出汗时进一步了解液体和电解质丢失。不要规定所有人每天固定几升、每次固定一瓶运动饮料或让体重因喝水而持续上升。限制液体/盐分的疾病遵循医疗指导。

若用户愿意且确有长时间运动需求，可用同条件运动前后体重、喝水量、时长等帮助估计汗量；它是个体化线索，不等同体脂变化。没有这些数据就不用伪精确的补液量。

## 记录和复查

保留用户确实报告的上一餐、饥饿、训练时间、补水及下一次训练；建议没有执行前标为建议。下次可问是否更舒服、胃肠是否耐受、训练/恢复是否更好；调整一个主变量，不同时强改总热量、碳水时机和训练量。

依据（2026-10-19核对）：[ISSN营养时机立场文件](https://link.springer.com/article/10.1186/s12970-017-0189-4)支持按训练与恢复条件考虑碳水/蛋白、重视全天摄入；[NATA补液立场文件](https://pmc.ncbi.nlm.nih.gov/articles/PMC5634236/)支持个体化补水并避免不足与过量。上表的沟通顺序与普通食物分支是本技能的实践编排，不是对每人已测得的营养处方。
