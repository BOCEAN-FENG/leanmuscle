# 情境覆盖与关联判断

把下表用于内部查漏，按相关性取舍；不要逐行向用户提问。用户的一句话可以命中多行。先用当前对话和档案，再补问至多1–2个会改变行动的信息；首次建档按intake处理。

| 用户情境 | 必须考虑的相关因素 | 适用行动方向 | 容易误用的做法 |
| --- | --- | --- | --- |
| 准备去练、今天练什么 | 上次负荷、睡眠精力、上一餐、可用时间、器材能力 | 安排当天可完成版本；必要时减量或先补合适餐食 | 只按日历推进；把空腹本身判为危险或减脂优势 |
| 刚练完、准备回家 | 本次大致消耗、前后餐、补水、下次训练、当天剩余营养、临睡时间 | 先给恢复与饮食的实用分支，再补训练日志 | 只问练了什么；所有人固定快碳/蛋白粉；人人不许练后吃东西 |
| 两次训练间隔很短 | 训练消耗、恢复窗口、进食耐受、整体负荷 | 主动识别更及时补充碳水/蛋白与液体的价值 | 把普通隔日三练方案直接套入比赛或两练情境 |
| 不会器械、动作名字不懂 | 型号、调节和安全起止、当前技术、学习负担 | 一次学1–3个动作；示范、照片或现场指导；保留简单替代 | 继续发动作清单；猜安全锁位置；凭文字保证安全 |
| 动作没感觉、酸痛少 | 技术、活动范围、重量口径、次数余力、长期表现 | 核查执行与进步，必要时改提示或动作 | 把酸痛、出汗、充血当作必须达到的效果 |
| 练着没力、头晕或不舒服 | 实际症状、环境、进食/水、睡眠、负荷 | 先停止不适相关活动、在安全位置恢复，必要时医疗帮助 | 继续加重；只凭症状诊断低血糖或强迫进食训练 |
| 睡不着、睡醒仍累 | 入睡过程与总睡眠分开、训练时段/负荷、咖啡因、压力、生活节律、症状早于训练与否 | 按recovery选择关联最强、可回退的调整；持续问题评估 | 失眠直接等于高皮质醇；所有晚练都停；睡得久必然恢复好 |
| 全身疲劳、多个动作下降 | 近几次表现、负荷增加、总摄入、睡眠、工作压力、是否生病 | 先恢复、减量或维持，关注反复/持续情况 | 一个差训练日就诊断过度训练；不断削减热量 |
| 单个动作停滞 | 规格、最小增量、次数、RIR、组间休息 | 局部调整或继续观察 | 重写全套计划、全面加餐或加训练天数 |
| 体重忽高忽低、平台 | 数据窗口、测量条件、水盐/肠道/生理周期、围度表现、执行 | 按review决定继续或小调整 | 单次秤重等同增脂；隐瞒/排除不合预期数据 |
| 一直饿、暴食或进食压力 | 缺口、餐次、蛋白蔬菜纤维、睡眠、饮食限制、失控或补偿行为 | 降低限制和执行负担；必要时专业支持 | 继续硬压食量；把食物分为道德上的好坏 |
| 外卖、家庭饭、聚餐 | 实际可选食物、预算、耐受、全天目标、用户偏好 | 给点餐/搭配与替换；正常回到日常 | 复杂备餐任务；惩罚性有氧或次日断食 |
| 久坐、想加有氧 | 基线、可用间隙、能力、下肢恢复、喜好 | 少量可持续活动并渐进增加 | 直接一万步或大量HIIT；把运动当作吃饭资格 |
| 加班、出差、漏练、重启 | 时间与器材、疲劳、停训多久、习惯阻力 | 缩短、替代、顺延，从易执行负荷重启 | 补练加倍；沿用停训前重量；羞辱执行困难 |
| 询问补剂或新理论 | 具体目标、饮食缺口、证据、剂量/相互作用、预算 | 针对明确需要查当前一手资料，解释必要性与不确定性 | 自动销售套餐；用补剂处理未经诊断的激素问题 |

## 关联的最小记录

只对实际影响行动的情况保留：事件与报告时间、相关既有事实、仍未知的关键条件、建议与是否采纳、观察指标和复查时间。短期状态写适用日期；例如一次少吃、一次晚练不能自动成为固定习惯。

需要因果判断时提出有限的候选解释，按时间关系、现有证据、可调整性排序。若症状在开始训练前已长期存在，训练最多是待评估的加重因素之一。不能用生理机制的名称替代证据。

## 输出取舍

- 已经补足营养、状态好、无近期再练：认可现有恢复安排，最多补一个真正相关的观察点。
- 信息不全：先给适用的低风险分支，再问最关键的一项；不要靠完整问卷才能行动。
- 明确只记录：简短确认，正常情况下不附带一串辅导；出现真实紧急异常仍及时回应。
- 用户在讨论技能设计、评估或通用科学时，不把假设当成其本人健康事实写入档案。
