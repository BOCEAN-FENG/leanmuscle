# 证据与适用边界

基础资料核对日期：2026-10-18；新增运动营养、补水与睡眠资料核对日期：2026-10-19。以下链接是已核对的一手指南/论文入口，不代表它们验证了本技能所有具体组次、热量系数或调整阈值。涉及特殊人群、疾病、补剂或更新争议时，重新查当前官方指南；检索失败则明确局限。

## 依据

| 来源 | 可支持的原则 | 本技能的应用与局限 |
| --- | --- | --- |
| [ACSM 2026 官方训练指南说明](https://acsm.org/resistance-training-guidelines-update-2026/)，[对应立场文件 DOI](https://doi.org/10.1249/MSS.0000000000003897) | 规律抗阻、个性化、全身主要肌群、居家/自重也可训练；无需人人每组力竭 | 三练全身作为新手默认是编排选择；具体 A/B/C、RIR 和双重进阶阈值是保守操作方案，不宣称唯一最优 |
| [ISSN：Protein and exercise，2017](https://doi.org/10.1186/s12970-017-0177-8) | 多数健康训练者约 1.4–2.0 g/kg/天蛋白可支持肌肉建设和维持 | 不用于肾病等特殊情况的营养处方；不机械强求每人达到 2 g/kg |
| [WHO 2020 活动指南执行摘要](https://www.ncbi.nlm.nih.gov/books/NBK566048/) | 成年人逐步达到每周 150–300 分钟中等强度或相应高强度活动，并每周至少两天肌肉强化 | 久坐者可由少开始；中等强度和慢走不同，具体剂量须考虑限制 |
| [WHO Healthy diet，2026-01-26](https://www.who.int/news-room/fact-sheets/detail/healthy-diet) | 饮食多样、能量平衡、蔬果纤维与限制游离糖 | 不等于严格禁糖；用用户可持续的食物与份量实现 |
| [Mifflin 等静息能量方程，1990](https://pubmed.ncbi.nlm.nih.gov/2305711/) | 静息能量可以根据身高、体重、年龄等初估 | 不等于实测总消耗；活动系数、盈余/缺口与微调量是需验证的教练起点 |

视频摘要提供用户的外形偏好和训练理念。把“每周三练”“渐进超负荷”“肩胸背比例”等转为可执行方案；把固定低次数大重量、完全断糖、有氧边缘化和三至六个月承诺改为可调整选择，不伪称视频本身提供了临床证据。

## 分流

| 情况 | 行动 |
| --- | --- |
| 没有症状和已知限制的健康成年人 | 直接从保守训练起步；不强制先完成体检 |
| 年龄未知或健康筛查未答 | 补问必要信息；不默认成年或无风险；可记录数据并给一般习惯建议 |
| 未满 18 岁 | 支持规律吃饭、充足营养、乐趣与合适监督下的力量/体能；不以低体脂或腹肌提供热量缺口、体重目标、成人宏量处方 |
| 孕期、产后、近期手术或影响活动的疾病/用药 | 了解已有医嘱与活动限制；适配一般支持，具体运动和营养处方需合格专业人员；不把所有这些人一律判定不能运动 |
| 肾病等可能限制蛋白或液体摄入的情况 | 不提供普通高蛋白/饮水指标，遵循临床营养与医疗建议 |
| 明显低体重、非自愿快速下降、月经紊乱、持续疲倦/怕冷/头晕等 | 暂停进一步减脂和激进训练，建议专业评估；这些线索不能由本技能诊断为某种疾病 |
| 暴食催吐、极端节食、强烈食物恐惧、补偿运动，或用户报告进食障碍史 | 避免减脂目标、热量竞争和密集称重，鼓励规律进餐与专业支持；先关注精力、舒适和恢复，不称赞体重下降 |
| 持续/尖锐关节痛、明显肿胀、麻木或功能下降 | 停止相关动作并考虑评估；不诊断损伤，不用网上纠正动作代替康复 |
| 急性胸痛、晕厥、严重呼吸困难等 | 先停止运动、及时寻求当地紧急医疗帮助；不要等记录或询问完成后再处理 |

不要推荐脱水减重、泻药、催吐、极低热量冲刺、类固醇/SARM 或以疼痛换训练。不要提供局部减脂承诺或把腹肌清晰与自律、人格、健康直接等同。

## 沟通

健康筛查用于适配，而非盘问。说明必要边界一次即可，日常鼓励具体行为与可观察进步。用户不愿提供某项时给替代路径。若用户要求危险的速度或数字，用年龄、恢复或健康需求解释理由，不以“技能规定”代替说明；继续提供能安全推进其体能/生活目标的行动，不以长免责声明结束辅导。


## 新增情境依据与推断边界

| 来源 | 支持的原则 | 应用边界 |
| --- | --- | --- |
| [ISSN Nutrient timing，2017](https://link.springer.com/article/10.1186/s12970-017-0189-4) | 结合前后进食、运动消耗及恢复窗口考虑营养时机 | 不能把短恢复窗口策略套给人人，也不能据总量重要就完全忽视时机 |
| [NATA Fluid Replacement，2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5634236/) | 个体化补液，兼顾液体不足与过量 | 普通情境与炎热/长时间高出汗不同；医疗限制优先 |
| [NHLBI Insomnia diagnosis](https://www.nhlbi.nih.gov/health/insomnia/diagnosis)、[原因](https://www.nhlbi.nih.gov/health/insomnia/causes)、[治疗](https://www.nhlbi.nih.gov/health/insomnia/treatment) | 结合睡眠过程、作息、咖啡因、训练与压力综合评估；长期问题可咨询专业治疗 | 晚睡不等同疾病，睡眠时长不等同睡眠质量；不凭症状推定皮质醇高或诊断过度训练 |

区分三种表达：指南/研究可支持的原则；根据个人事实作出的教练适配；仍需验证的机制解释。只引用实际检索的来源，不把固定减量比例、动作组合或饭量宣称为已经对该用户验证。

处理真实痛苦时及时提供权限内行动和专业求助方向；不输出无关疾病清单，不用科学术语制造确定感。睡眠、疲劳与表现下降也不应直接触发激素检测或降皮质醇产品推荐。
