# 训练编排与进阶

以下是健康成年人的保守编排起点，不是唯一有效方案或医疗处方。按经验、器材、疼痛、时间与恢复取舍。技术性原则的来源见 evidence-safety.md；具体动作组合和进阶阈值属于本技能的操作规则。

## 选择频率与结构

| 可用条件 | 默认安排 | 取舍 |
| --- | --- | --- |
| 新手，每周 2 天 | 全身 A/B，尽量不连续 | 每次包含下肢、推、拉，建立习惯 |
| 新手，每周 3 天 | 全身 A/B/C，隔日安排 | 每周多次练习主要动作，兼顾肩胸背与腿 |
| 每周 4 天且恢复良好 | 上肢/下肢各两次 | 把总量分散，仍有休息日 |
| 明确喜欢每周三天推拉腿 | 保留推/拉/腿及适量外形补强 | 提醒多数肌群每周集中一次；并非无效，也无需强迫改为六练 |
| 单次只有 20–30 分钟 | 3 个主要动作，各 2 组 | 缩小目标，不压缩所有休息硬塞完整计划 |
| 居家/无健身房 | 按器材替换同类动作 | 坦诚无安全拉类器材的限制 |

优先覆盖蹲/膝主导、髋主导、推、拉与核心；在总量可恢复的基础上强调上胸、肩中后束和背部。保留腿和臀部训练，不以“薄肌”为理由完全跳过。不要把面拉或某个动作宣称为治疗体态问题的万能动作。

## 训练强度与时长

- 新手最初 1–2 周可每动作 1–2 个正式组、保留约 3–4 次余力，先学稳定动作。随后按恢复加到 2–3 组、约 2–3 次余力。RIR 是估计，不要求新手精准判断。
- 大部分复合动作可用 6–12 或 8–12 次范围；辅助动作可用 10–20 次。视频中的 3×4–6 次是一个选项，不能把偏重低次数当作所有新手起点，也不要求先测 1RM。
- 复合动作组间通常 2–3 分钟，辅助 60–120 秒；时间不足先删辅助或减组，不用仓促休息换数量。
- 每次先做 5–10 分钟适合的轻松活动与动作热身，首个较重动作逐渐加重热身；热身不计正式组。技术不熟的动作建议获得合格教练的现场反馈。
- 从每主要肌群每周约 6–10 个有质量的正式组这一可调整起点出发；一开始可更少。不要机械把复合动作涉及的每个肌群都算作足量直接训练；同时考虑叠加疲劳。
- 多数新手不需要每组力竭。动作变形、关节锐痛或异常不适不是进阶指标。

## 可裁剪的三天全身骨架

这不是已经替用户生成的计划。输出时按设备和限制选择一个动作、明确组次，删除多余备选；估算加上热身、休息和换器械的总时长。

| 日 | 主要动作 | 外形与核心补充 |
| --- | --- | --- |
| A | 高脚杯深蹲或腿举 2–3×6–12；上斜哑铃卧推 2–3×8–12；坐姿划船 2–3×8–12 | 侧平举 2×12–20；死虫 2×每侧 6–10 |
| B | 罗马尼亚硬拉或臀桥 2×8–12；高位下拉 2–3×8–12；分腿蹲 2×每侧 8–12 | 合适时哑铃肩推 2×8–12；抗旋转训练 2×每侧 8–12 |
| C | 腿举或蹲类 2–3×8–12；平板或上斜推举 2–3×8–12；胸托划船或下拉 2–3×8–12 | 腿弯举 2×10–15；侧平举或后束飞鸟 2×12–20 |

初次练习髋铰链可先选简单可控的臀桥，之后再学硬拉；传统硬拉不是必做项。只有 45 分钟时减到四个动作或删一项补充；只做 20–30 分钟时优先下肢、推、拉各两组。不要删除所有热身。

## 居家替换

| 动作模式 | 候选 |
| --- | --- |
| 胸部推 | 墙/稳固高台俯卧撑 → 普通俯卧撑 → 合理加难；有哑铃可地板推 |
| 蹲与腿 | 徒手蹲、分腿蹲、已知负重的高脚杯蹲 |
| 髋 | 臀桥、哑铃罗马尼亚硬拉（先学技术） |
| 拉 | 哑铃/可靠负重划船，合格固定的弹力带划船/下拉，安装可靠的单杠引体 |
| 肩与核心 | 轻哑铃侧平举、死虫、侧支撑等合适变式 |

不让用户把不明承重的桌子、门框、家具当作悬挂点；弹力带固定点必须可靠。没有安全拉类条件时说明方案缺口，询问现有器材或给不依赖悬挂的替代，不把俯卧撑误称为完整的背部训练。

## 选重与双重进阶

1. 初次选能以稳定动作完成目标范围下端、尚有 2–4 次余力的负重；宁可偏轻，不凭身高体重猜卧推或深蹲公斤数。
2. 保持动作规格和重量口径一致，先逐步增加次数。比如 3×8–12 的实际完成可能是 10/9/8，记录原值。
3. 所有正式组连续两次训练达到次数上限、余力符合目标、技术稳定且无疼痛，再考虑最小可行加重；常见起点约 2%–5%，需匹配器械档位，不能强制此比例。
4. 加重后回到次数范围下部。哑铃记录每只重量；最小增量太大时先维持、加少量次数或选更合适器械，不无脑跳档。
5. 连续表现下降时先检查睡眠、饮食、技术与累积疲劳；必要时短期减正式组约三分之一至一半，或降低负重。这是恢复策略，不是惩罚。
6. 某动作疼痛时暂停该动作的进阶，了解性质与诱因；持续或明显症状寻求评估，不诊断、不要求忍痛完成。

自重动作也按相同逻辑记录变式、活动范围、次数与附加负重，逐次改变一个因素。练得更慢不等于可无限代替负重进步。

## 有氧与恢复

对适合的成年人，把逐步靠近每周 150–300 分钟中等强度活动作为长期健康方向；从现有能力开始，短时间快走、骑车等也有意义，不能第一周硬塞满。慢走不自动等同中等强度，快走可用“能说话但不易唱歌”作粗略参照。

用每日活动和规律睡眠支持恢复；不把步数门槛、出汗量或有氧消耗当作允许吃饭的资格。避免把大量高强度有氧突然加在疲劳的腿日。漏练后调整日期顺延，保留恢复空间。


## 当天情境适配

排课前核对相关恢复、进食、设备能力和时间。器械不会先按核心技能的technique资料教少量动作；当天只有短时间时缩短而不匆忙。准备/刚结束训练同时按workout-nutrition判断即时营养和补水。睡眠、疲劳或疼痛改变安排时按recovery分析，并区分当次减量与长期计划调整。

按用户明确请求和已有条件输出具体动作；不要用上述核对作为必须先填完全部健康与餐食日志的门槛。知识解释不强制建档。
