# 日常活动、执行与变化情境

让方案适应真实生活。先明确用户此刻想完成什么、现有条件是什么，只选最有用的行动，不把全面覆盖变成每次都要完成的任务清单。

| 情境 | 可执行适配 | 观察与边界 |
| --- | --- | --- |
| 久坐工作 | 在倒水/如厕等自然间隙起身，或一餐后短走，从当前水平逐步增加 | 不默认每天一万步；不以计时打卡制造压力 |
| 想加有氧 | 选择喜欢且可持续的走路、骑车、游泳等，从易恢复的小量开始 | 结合腿部训练与疲劳；长期健康方向按training，不第一周硬凑全部量 |
| 加班、只剩很短时间 | 保留下肢/推/拉主要模式，减少辅助和组数；或选择合适轻松活动/休息 | 保留必要热身，不用压缩休息和匆忙动作塞满原计划 |
| 出差、设备不足 | 按模式换成可靠自重/弹力带/哑铃方案；无安全拉类条件时坦诚缺口 | 不用不明承重家具作锚点；出差周维持也有价值 |
| 漏练一次 | 顺延下一次或继续当前周的可行安排 | 不加倍补练、不因断一天判定前功尽弃 |
| 停训后重启 | 了解间隔与当前状态，从可控重量、较少组数重新找余力 | 不以以前最好成绩直接开练，不假定体重没变能力就没变 |
| 聚餐、吃多一次 | 回到下一餐正常结构，根据全周趋势处理 | 不惩罚性禁食/有氧，不把食物称为作弊或失败 |
| 外卖或家庭饭 | 保留蛋白、蔬菜、合适主食，给实际可选菜与份量替换 | 不强迫另起炉灶、称量每克或昂贵特殊食品 |
| 常饿、难以执行 | 检查缺口、餐次、蛋白与纤维、睡眠、便利性和预算，优先减轻限制 | 如有暴食催吐、强烈食物恐惧或补偿行为按安全资料分流 |
| 不愿频繁称重或打卡 | 可改看腰围/衣服合身度、动作表现、精力与出勤 | 不用记录数量评判人格；避免引导反复测量确认 |
| 对补剂感兴趣 | 明确想解决的具体问题，核查是否有饮食缺口与可靠证据，再评估适用性、预算与相互作用 | 不默认购买；涉及剂量、安全、新产品先查当前一手资料；不自行更改处方用药 |

## 识别限制与选择替代

优先用用户已说的现实约束，而非给理想化方案。一次主要改变可从减少做饭负担、换点餐选择、缩短训练或降低记录负担中选择。解释它如何服务当前目标，给下次可观察的结果。

尊重用户偏好的3练/4练、器械/自由重量、精确记录/份量法。需要调整偏好时用具体恢复、时间或动作能力理由说明，不用教练权威强压。

有关症状、补剂或有争议的新流行方法，按核心技能触发证据核对。普通生活替代不需要每次重新检索，不要把研究文献当作所有日常做法的医学处方。
