# 复盘与调整

## 先读什么

读当前计划、上次调整及其日期、最近 2–4 周实际训练、有效体重/腰围、饮食与恢复。先回应本次诉求；用户只给一条日志时不强制输出完整周报。

尽量每周做简短复盘，每四周检查阶段与动作是否仍适合。复盘日期需要用户反馈才会发生；只有用户提出提醒需求且自动化创建成功时，才可承诺提醒。

## 数据质量与计算

1. 使用用户当地的绝对日期和一致测量条件。排除已作废、重复或单位未确认记录，保留原始值，不擅自丢弃不合期望的数据。
2. 比较相邻、不重叠的两个七天窗口，例如截至 10 月 18 日：前窗 10 月 5–11 日、后窗 10 月 12–18 日。每窗至少三个不同日期才输出供复盘使用的均值变化；这是本技能的最低数据要求，不是医学阈值。
3. 用脚本防止斤/kg混用、遗漏日期和错误均值。只把已确认有效且条件可比的体重提取到临时 JSON，真实档案仍以 muscle.md 为准。

```json
{"observations":[{"date":"2026-10-05","weight":140,"unit":"jin"},{"date":"2026-10-12","weight":69.8,"unit":"kg"}]}
```

此为格式示例，不能写入真实档案。`jin` 仅表示已确认的大陆市斤（0.5 kg）；`lb` 为国际磅。调用：

```bash
python3 <技能目录>/scripts/weight_trend.py --as-of YYYY-MM-DD --input <临时JSON路径>
```

也可省略 `--input` 从标准输入读取。脚本只输出 JSON，不读写 muscle.md、不联网、不做饮食处方。两个窗口样本不足时 `comparison` 为 null；不得把 `sample_mean_kg` 说成有充分记录的周趋势。重复同日读数、未来日期或无效单位会报错，先解决原始数据，不用修改脚本绕过。

4. 比较结果只代表两个采样窗口的均值差，不代表精确脂肪或肌肉变化。采样日分布不同、测量条件不同或生理周期等都影响解释；必要时扩大观察到三四周。
5. 只有一个合格窗口时，可以描述该窗均值但不能宣称相较上一周如何变化。不能从两次单日称重断言“平台期”。

## 决策顺序

| 观察 | 默认行动 |
| --- | --- |
| 数据不足、才更改计划几天、单位或测量条件不同 | 保持当前可执行方案，补齐关键数据，给明确观察窗口 |
| 体重接近不变、腰围下降、训练表现提高 | 视作可能的积极身体重组，先维持；不为了秤上数字强减食量 |
| 当前方向合理、训练和恢复良好 | 继续；能执行的计划不需要每周换动作 |
| 训练出勤或饮食执行困难 | 先减小执行负担和处理障碍，不先降低热量或增加训练 |
| 合理减脂阶段，连续 2–3 周趋势不变，记录可靠且方案执行稳定 | 可只选一种小调整：如减少约 100–150 kcal/天的一项食物份量，或略增适合的轻松活动；再观察约两周 |
| 增肌阶段，数周体重与表现均无进步，恢复与记录充分 | 先检查技术和训练量；确需饮食调整时小幅加餐约 100–150 kcal/天，再观察 |
| 体重变快、训练明显下滑、持续饥饿疲劳或头晕等 | 减小能量缺口/训练负担并了解症状；按安全参考处理，不等待凑齐数据再照顾症状 |
| 只一个动作停滞 | 检查动作规格、RIR、休息与最小负重增量，不立即重写整个训练计划 |
| 多个动作连续下降、恢复差 | 优先安排短期减量、恢复和足够饮食，必要时专业评估 |

表中的调整量属于可回退的实践起点，非普遍适用处方；健康风险分流优先于任何趋势规则。不要为快速达成体形目标不断叠加热量削减和有氧。

## 输出及写回

给简短比较表：指标、上一窗口、本窗口、解释；缺失项显示“数据不足”。然后给一个结论、最多一两个本周行动、下一次日期和必要记录。没有依据时明确“先维持”，不为了显示教练价值制造变化。

写回复盘日期、覆盖天数、原始数据位置、计算结果、恢复情况、决定及依据。改计划时先保留旧版本与原目标，再更新当前版本，记录实施时间；建议尚未采用时标为待采用。保存成功后提供文件入口与一句反馈。


## 即时适配与调整尝试

真实不适、训练当天的明显疲劳、吃饭与补水需要，不必等周复盘才回应。区分当次临时适配和长期变更；一次主变量，给出观察与停止/回退条件。

复盘不仅比较体重和训练次数，也检查已建议调整的执行情况及结果。例如更换训练时段后，在可比训练日/休息日观察入睡过程、精力和表现；记录同时发生的其他变化，不宣称从几次反馈证实了激素病因。没有执行或资料不足时不能判定措施无效。

有效稳定时继续，某项营养已落实时不再加码，症状恶化时及时重新评估。向用户总结最重要的结论与下一步，历史字段写入档案即可，不把整份内部检查表作为回复。
